# TreinoDB
 Aplicação Web para gerenciamento de treinos na academia.
 
## Sobre o Projeto
 Ele foi desenvolvido com o intuito de ser uma ferramenta prática e fácil para o registros do pesos utilizados em treino na academia.

## Histórico
 - **v.1.2 -** Organização e Atualizações | Lançamento: 29/10/2026
   - **Novidades:** Organização de scripts do  projeto, atualização na tela de login, adição de botão para treinos da categoria "Geral" e mudança de cores nos ícones dos exercícios.
 - **v.1.1 -** Projeto Inicial | Lançamento: 10/05/2026
   - **Novidades:** Adição de campo para salvar a quantidade de repetições.
 - **v.1 -** Projeto Inicial | Lançamento: 30/04/2026
   - **Novidades:** Registro e consulta dos exercícios (ou máquinas) com a quantidade de peso. Também possui a tags para filtrar por treino.
